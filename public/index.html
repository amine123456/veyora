Web Unlocker

Send a URL. Get the page back.

The Web Unlocker API fetches a public page for you with a single request. We pick the exit, retry blocked requests on new residential and mobile IPs, and keep cookies per session.

  • We pick the exitNo pool to manage. Add a country to the request if you want a specific one.
  • Blocked? It retriesBlocked requests are retried on new residential and mobile IPs until the page comes back.
  • Sessions keep their cookiesName a session to keep the same exit and cookies across requests.
  • Pay only for pages returnedBilled per request from the same prepaid balance as your proxy traffic. You are charged only when the page comes back.
